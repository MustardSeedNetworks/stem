# UI coverage ratchet (#824).
#
# FLOOR is enforced by scripts/check-ui-coverage.sh in CI: coverage may not
# drop below it. TARGET is where #824 says the suite has to get to, and is
# deliberately NOT the enforced number — the thresholds in vitest.config.ts
# were set to the target and never wired into CI, so nothing was enforced at
# all and the real figure drifted down unnoticed.
#
# The floor is raised by whoever improves coverage, in the same PR. It is
# never lowered: a drop is a regression to fix, not a number to edit.
#
# Recalibrated once, 2026-09-17 (#1348), for the only reason that justifies it:
# the denominator changed, not the coverage. The 22 locale JSON namespaces were
# inside ui/ and v8 counted each one as fully covered, adding 192 always-covered
# "lines" that no test asserted anything about. They now live in
# internal/i18n/locales/ and coverage excludes **/*.json outright, so the figure
# below measures code alone. Proof it is not a regression: branches and
# functions moved 0.00 -- JSON has neither -- while statements and lines each
# fell ~0.9. Same tests, same assertions, honest denominator.
#
# metric      floor   target
statements    69.9    88
branches      54.6    80
functions     67.7    92
lines         81.5    88
