# Release-candidate checklist — v0.27.2 on Ubuntu and Fedora, 2026-10-15

**Question.** Does the shipped v0.27.2 package install, set up, run one
RFC 2544 and one Y.1564 test, and do what the README says, on each platform
it ships for?

**Answer.** Yes on Ubuntu 26.04 and Fedora 44: both signed packages install,
first-run setup completes, `/__version` reports a non-empty `uiBuildHash`, and
an RFC 2544 throughput search and a Y.1564 configuration test pass in each
direction between the two hosts. Every README claim checked holds except one:
the packaged service never runs on AF_XDP
([#1747](https://github.com/MustardSeedNetworks/stem/issues/1747)). The macOS
leg was not run (below).

## Setup

| | Ubuntu | Fedora |
| --- | --- | --- |
| Host | dev-srv-ubuntu, Ubuntu 26.04.1 LTS, kernel 7.0.0-38 | dev-srv-fedora, Fedora 44 Server, kernel 7.2.8-200.fc44 |
| Package | `stem_0.27.2_amd64.deb` | `stem-0.27.2-1.x86_64.rpm` |
| Interface | `ens18` (virtio, one L2 segment) | `ens18` |

Both packages, their SBOMs and `checksums.txt` were downloaded from the v0.27.2
release and verified with `cosign verify-blob` against the keyless bundle
before install.

### macOS — not run

No macOS package ships (`deploy/macos/build-pkg.sh` is a local convenience,
README "Build"), and the macOS build is a portable `CGO_ENABLED=0` binary with
no dataplane, so there is no RFC 2544 or Y.1564 leg to run there. The
install / first-run / `/__version` half of the Mac leg is still open.

## Findings

- [#1747](https://github.com/MustardSeedNetworks/stem/issues/1747) — the
  packaged service lacks `CAP_PERFMON`, so AF_XDP never loads on Ubuntu or
  Fedora, the log names the wrong platform, and the fallback message blames
  the NIC.
- One security finding was handed to the owner for private disclosure under
  `SECURITY.md`. It is not described here.
- `/api/v1/events` serves reflector counters to an unauthenticated client
  while the equivalent REST route requires a JWT. Not filed.
- `stem list-tests` prints raw hex colour codes (`Benchmark [#dc2626]`) and
  most test types have empty descriptions. Not filed.
- The CLI progress line estimates "~20s left" for a throughput search that
  ran 70 s. Not filed.
- The trial reports 13 days remaining minutes after a 14-day start. Not filed.
- The `.deb`/`.rpm` description advertised "WebUI/TUI/CLI workflows"; the TUI
  was deleted (STM-5). Fixed in this change (`.goreleaser.yml`). The
  reflector config still carries a dead `TUIConfig`
  (`internal/reflector/config/config.go`). Not filed.
- The package `License` field reads `Proprietary` while `LICENSE` and the
  README say Business Source License 1.1. Left for the owner; licence labels
  are not changed from an audit.
